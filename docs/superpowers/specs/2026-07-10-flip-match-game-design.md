# 翻牌消消乐 — 设计文档

## 概述

一个日系清新风格的记忆配对翻牌小游戏。纯 HTML 单文件实现，零依赖，打开即玩。玩家翻开卡片找出 emoji 配对，全部消除后通关，可生成分享卡片。

---

## 技术方案

- **实现方式**：单个 `index.html` 文件，内联 `<style>` 和 `<script>`
- **零依赖**，无外部框架或库
- **分享卡片**：Canvas 离屏渲染 + QR 码 API，遵循 share-card-generator 规范

---

## 难度配置

| 难度 | 棋盘 | 牌数 | 配对数 |
|------|------|------|--------|
| 简单 | 4×4 (4列) | 16 | 8 |
| 普通 | 4×6 (6列) | 24 | 12 |
| 困难 | 6×6 (6列) | 36 | 18 |

Emoji 池预置 20+ 个，每局随机抽取所需对数。

## 视觉设计

**主题**：日系清新（对应分享 skill 的 `fresh` 主题）

| 元素 | 值 |
|------|-----|
| 主色 | `#81C784` |
| 背景渐变 | `#e8f5e9` → `#fafafa` |
| 卡片正面（未翻开）| 白色，浅绿边框，圆角，阴影，`?` 图案 |
| 卡片背面（翻开）| 白色底，居中大号 emoji |

**布局**：移动优先，CSS Grid 棋盘，桌面居中最大宽度限制。

## 交互流程

### 游戏状态机

```
选难度 → 洗牌发牌 → 等待翻牌
  → 翻开第一张 → 翻开第二张
    → 匹配成功：保持翻开，缩小标记
    → 匹配失败：0.6s 后翻回
  → 循环至全部消除 → 通关弹窗
```

### 核心状态

```
{
  difficulty: 'easy' | 'normal' | 'hard',
  cards: [{ emoji, flipped, matched }],
  firstCard: index | null,
  secondCard: index | null,
  isLocked: boolean
}
```

### 关键交互规则

- 翻牌期间锁定点击（`isLocked`），防止同时操作
- 点击同一张牌不触发匹配逻辑
- 匹配成功：两张牌短暂高亮 → 缩小/半透明标记"已消除"
- 匹配失败：两张牌 0.6s 后翻回
- 全部消除：600ms 延迟后弹出通关弹窗
- 随时可切换难度或重新开始

## 分享功能

### 触发

通关弹窗中显示"📤 分享给朋友"按钮。

### 分享卡片规格

| 字段 | 值 |
|------|-----|
| 尺寸 | 1200×1600 |
| 标题 | "翻牌消消乐" |
| 副标题 | "日系清新记忆配对小游戏" |
| 特性 | 当前难度 + 消除配对数 |
| 主题 | 日系清新：浅绿渐变背景，白色圆角内容卡片 |
| QR 码 | `api.qrserver.com` 生成，右下角 |

### 技术实现

1. 离屏 Canvas 绘制分享卡片
2. `toDataURL('image/png')` 导出
3. 全屏遮罩层展示，支持微信长按保存
4. 点击关闭或背景区域关闭

### 分享 CSS 样式

- 分享按钮：虚线边框 `1.5px dashed #81C784`
- 遮罩：`rgba(0,0,0,0.7)`
- 关闭按钮：圆角半透明
